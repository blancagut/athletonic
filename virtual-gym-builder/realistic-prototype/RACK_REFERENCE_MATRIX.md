## Planning estimates

- Linear default spacing is 2.80 m. It is user-adjustable from 1.20 m to 5.00 m and is checked against each pair of mounted products.
- Linear post and beam sections are visual planning profiles, not fabrication drawings. A structural engineer must specify gauge, welds, fasteners, slab anchors and seismic requirements for the installation site.
- Radial arm length is 1.40 m. No manufacturer capacity is claimed; the inspector reports that its load is not published.
- Speed-platform envelope is 0.82 x 1.15 x 2.35 m. Only the drum pattern and adjustment mechanism are reference-derived.
- Double-end ceiling height defaults to 3.00 m and tension to 0.55 as planning parameters. The model does not certify a ceiling substrate.
- Working-area warnings are planning checks, not a substitute for manufacturer installation clearances or local codes.

## Known limitations

- Product mass is not available in the current equipment catalog, so maximum-load warnings can display station capacity but cannot yet compare actual filled bag weight.
- Neighbor conflict checks currently use product width plus catalog operational clearance; they do not simulate dynamic pendulum motion.
- Reduction of an occupied linear rack requires confirmation and detaches removed products beside the rack. Their exact collision-free landing position remains a planning approximation.
- The mounted visual uses the existing catalog dimensions and does not alter them. Licensed product meshes can replace the provisional visual when approved assets are registered.
- Wall-mounted speed platforms are not yet offered; the implemented variant is the independent floor stand.
